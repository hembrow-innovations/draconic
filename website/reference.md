# Reference

Working pages kept open while writing a Program. Not a generated API dump, and not the Learn path.

Open a page when you already know you need that surface:

- [CLI](cli.html) — command names, run default, permission flags, shebang. Shipped.
- [types](types.html) — Checker versus tsc, JS values versus native types, portable versus native-only versus JS-only
- [Dual-world rules](dual-world-rules.html) — explicit boundaries, heap versus unboxed, backend hard-error
- [host I/O](reference-host-io.html) — process, stdio, filesystem, sockets, HTTP/1.1
- [packages](reference-packages.html) — git identity, manifest, lockfile, get and tidy

Each page is tagged shipped or not-yet. Copy-paste samples appear only on shipped pages. If you are new to the language, start at [Learn](learn.html) instead.
