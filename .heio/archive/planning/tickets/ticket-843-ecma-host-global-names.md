# What do ECMA-262 and hosts name the global object?

## Signal

AFK research for [[rounds-842-global-object-identifier]]. What identifier does ECMA-262 give Programs for the global object? What do Node, browsers, and Deno add as host aliases, and which of those are legacy?

## Fit

Wayfinder research. Findings go under Notes. Do not choose Draconic's identifier here.

## Notes

- **ECMA-262**: Programs access the global object through `globalThis` (`#sec-globalthis`). MDN: this is the standard cross-environment name. The TC39 naming discussion dropped `self` and `global` because they could break existing code.
- **Browsers**: historical names are `window`, `self`, and `frames`. Web Workers only have `self`.
- **Node.js**: `global` is Stability 3 Legacy. Docs say use `globalThis` instead. Node also exposes free `console`; Draconic does not.
- **Draconic today**: Checker installs builtin `globalThis` only. ROADMAP E15.01 and `language.ecma:builtins` name `undefined`/`globalThis`.

Answer: the language standard name is `globalThis`. Host `global` is a Node legacy alias, not ECMA-262.
