# H13 HTTP/2 (later; not v1 bar)

## Why

ROADMAP H13 locks the Host HTTP/2 surface on native (ADR-0008 sockets-first; HTTP/2 later than plaintext HTTP/1.1, not the v1 bar). H13.01 already lands preface + single-stream request/response; this cut is the parent row that those ops form one honest HTTP/2 surface.

## Done

ROADMAP H13 is implemented test-first on native. A Program can emit HTTP/2 client and server connection prefaces (`http2ClientPreface` / `http2ServerPreface` / `http2SettingsAck`), encode and parse a single-stream request and response (`http2EncodeRequest` / `http2EncodeResponse` / `http2ParseRequest` / `http2ParseResponse`), and complete a one-buffer client open plus server reply (`http2ClientOpen` / `http2ServerReply`). Tests under `tests/conformance/host/http2` lock that combined surface. Mark H13 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **H13.01**: HTTP/2 preface + single stream request/response (already `done`)
- **H06**: TCP listen/accept/connect/read/write
- **H10**: HTTP/1.1 thin helpers (plaintext)
- **H11**: TLS
- **H12**: WebSocket
- **H00**: host I/O surface policy
- multiplexed streams, push, or a full HTTP/2 stack beyond the single-stream helpers
