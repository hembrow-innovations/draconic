# H01 Process: args, env, exit

## Why

ROADMAP H01 locks the Host process surface on both targets: program args, env get/set/delete, and `exit(code)` / exitCode (plus read-only pid/ppid). H01.01–H01.04 already land those pieces; this cut is the parent row that those ops form one honest process control surface.

## Done

ROADMAP H01 is implemented test-first on both targets. A Program can read argv as a string array, get/set/delete env string values (missing → undefined), terminate with `exit(code)` / exitCode (default 0), and read pid/ppid. Tests under `tests/conformance/host/process` lock that combined surface. Mark H01 `done` only when those tests are green.
