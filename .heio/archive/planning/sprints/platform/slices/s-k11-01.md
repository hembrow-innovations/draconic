# K11.01 Private git auth (HTTPS token / SSH)

## Why

ROADMAP K11.01 locks post-v1 private git auth on the compiler target (ADR-0009 git-backed packages). Fetch of a private module may use an HTTPS token or SSH credentials so clone/fetch is not limited to anonymous HTTPS.

## Done

ROADMAP K11.01 is implemented test-first on the compiler target. Package fetch can authenticate to a private git host with an HTTPS token or SSH (as designed); missing or rejected credentials fail closed with a clear diagnostic and do not write secrets into `draconic.toml` or `draconic.lock`. Tests in `crates/draconic-pkg` and `crates/draconic-cli` lock that surface. Mark K11.01 `done` only when those tests are green.
