# K01 Manifest (`draconic.toml`): module path, deps, optional path→git URL map

## Why

ROADMAP K01 locks the git-backed package manifest surface (ADR-0009): `draconic.toml` carries the Program's own module path, a deps map (path → version req), and an optional path→git URL map when default URL derivation is wrong. K01.01–K01.04 already land parse, stable write/round-trip, schema diagnostics, and default `https://{module_path}.git`; this cut is the parent row that those ops form one honest manifest.

## Done

ROADMAP K01 is implemented test-first on the compiler. A Program's `draconic.toml` parses own module path plus deps, round-trips with stable order, rejects invalid schema with diagnostics, and resolves git URLs from the optional map or default derivation. Tests in `crates/draconic-pkg` lock that combined surface. Mark K01 `done` only when those tests are green.
