# K07 Build integration: auto-fetch; `--offline`

## Why

ROADMAP K07 locks build integration for git-backed packages on the compiler target (ADR-0009). `draconic build` auto-fetches missing locked cache entries, `--offline` stays cache-only with a fixit on miss, and a present lock is the pin set (no floating). K07.01–K07.03 already land those ops; this cut is the parent row that they form one honest auto-fetch / `--offline` build surface.

## Done

ROADMAP K07 is implemented test-first on the compiler target. `draconic build` materialises missing locked package checkouts before compile; `draconic build --offline` consults cache only and hard-fails with a `draconic get` / without-`--offline` fixit on miss; when a lock is present, build uses those pins and does not float versions. Tests in `crates/draconic-cli` (`build`) and `crates/draconic-pkg` (`ensure`) lock that combined surface. Mark K07 `done` only when those tests are green.
