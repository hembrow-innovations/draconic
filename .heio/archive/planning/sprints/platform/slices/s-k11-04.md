# K11.04 Module proxy/mirror (git still canonical)

## Why

ROADMAP K11.04 locks a post-v1 module proxy/mirror on the compiler target (ADR-0009 git-backed packages). Fetch may go through a configured proxy or mirror (Athens/GOPROXY-shaped) while git remains the canonical module identity and source of truth — lock pins and content hashes still name the git tree, not the mirror.

## Done

ROADMAP K11.04 is implemented test-first on the compiler target. A configured module proxy/mirror can serve fetch while module path identity, lock OID, and tree hash stay git-canonical; a missing or failing proxy does not rewrite identity to the mirror URL. Tests in `crates/draconic-pkg` lock that split. Mark K11.04 `done` only when those tests are green.

None.

## Non-goals

- **K11.05**: Yank/retract when advisory source configured
- **K01.04**: optional per-module path→git URL map (identity derivation, not a proxy)
- a central npm/crates.io registry as canonical source (rejected as v1 primary in ADR-0009)
