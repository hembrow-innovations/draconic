# D05.01 CLI/build flags: strip symbols

## Why

ROADMAP D05.01 makes native binary size honest at the CLI: `draconic build` exposes a strip-symbols flag so a shippable native artifact can drop debug symbols. Distribution already produces host binaries; this cut stops leaving strip as an after-the-fact `strip(1)` folklore step.

## Done

ROADMAP D05.01 is implemented test-first on the native target. CLI/build flags strip symbols from native artifacts. Tests under `crates/draconic-cli` and `tests/integration` lock that the flag is invokable and that a stripped binary is smaller or lacks the symbols the unstripped build kept. Mark D05.01 `done` only when those tests are green.
