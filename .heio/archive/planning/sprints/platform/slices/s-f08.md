# F08 Unsafe/native-only FFI diagnostics; JS hard-error; clear spans

## Why

ROADMAP F08 locks unsafe/native-only FFI diagnostics on both targets (N04 spirit; Dual-world explicit boundary, ADR-0003). F08.01–F08.02 already land js hard-error for FFI/extern and clear spans plus codes for bad extern signatures / unsupported types; this cut is the parent row that those ops form one honest FFI policy surface. F08 is on the F v1 done bar.

## Done

ROADMAP F08 is implemented test-first on both targets. `extern "C"` / FFI on js is a hard diagnostic (never silent wrong code). Bad extern signatures and unsupported types emit clear spans and codes on js and native. Tests under `tests/conformance` fixtures `ffi/policy` lock that combined surface. Mark F08 `done` only when those tests are green.

## Blocked by

None. F08.01 and F08.02 already land the per-class fixtures this parent row unifies.
