# K11.05 Yank/retract when advisory source configured

## Why

ROADMAP K11.05 locks post-v1 yank/retract on the compiler target (ADR-0009 git-backed packages). When an advisory source is configured, a yanked or retracted version is refused at resolve/fetch instead of silently installing.

## Done

ROADMAP K11.05 is implemented test-first on the compiler target. With an advisory source configured, package resolve/fetch hard-fails a yanked or retracted version and does not pin it; with no advisory source configured, yank is not invented as a silent v1 check. Tests in `crates/draconic-pkg` lock that refuse path. Mark K11.05 `done` only when those tests are green.
