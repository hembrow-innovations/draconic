# F02 C callbacks: Draconic fn as extern C pointer; host invokes

## Why

ROADMAP F02 locks C callbacks on native (Dual-world explicit boundary; ADR-0003 GC runtime and dual worlds). F02.01–F02.02 already land export of a Draconic fn as a C function pointer and host invoke with scalar args so the return is observed; this cut is the parent row that those ops form one honest native callback surface.

## Done

ROADMAP F02 is implemented test-first on native. A Program can pass a Draconic fn as an `extern "C"` pointer and the host can invoke it with scalar args so the return value is observed. Tests under `tests/conformance` fixtures `ffi/callback` lock that combined surface. Mark F02 `done` only when those tests are green.
