# H04 Filesystem: read / write / dirs

## Why

ROADMAP H04 locks the Host filesystem surface on both targets: read, write, and directory ops. H04.01–H04.06 already land whole-file read/write, exists/stat, mkdir/readdir/rmdir, rename/copy/delete, and native open handles; this cut is the parent row that those ops form one honest filesystem surface.

## Done

ROADMAP H04 is implemented test-first on both targets. A Program can read whole-file bytes and UTF-8 text (missing → typed error), write/append/create/truncate, `exists` / `stat` (size, isFile, isDir, mtime), mkdir (optional recursive) / readdir / rmdir / remove file, and rename / copy / delete file. Native also opens an fd-like handle (open/read/write/seek/close). Tests under `tests/conformance/host/fs` lock that combined surface. Mark H04 `done` only when those tests are green.
