## Why

ROADMAP K05 locks the package CLI surface on the compiler target (ADR-0009 git-backed packages). K05.01–K05.02 already land `draconic get <module_path>@<ver>` (fetch, update manifest+lock+cache) and `draconic mod tidy` (lock matches manifest; fetch missing; prune unused); this cut is the parent row that those ops form one honest get/tidy CLI.

## Done

Tests in `crates/draconic-cli` (`get`, `mod_tidy`) lock that combined surface. Mark K05 `done` only when those tests are green.
