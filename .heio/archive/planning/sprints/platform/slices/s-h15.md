# H15 Subprocess

## Why

ROADMAP H15 locks the Host subprocess surface on both targets (ADR-0008 host I/O). H15.01–H15.03 already land spawn/run (argv, env subset, cwd, wait exit code), capture stdout/stderr plus stdin write and kill, and native async wait via the job queue; this cut is the parent row that those ops form one honest subprocess surface.

## Done

ROADMAP H15 is implemented test-first on both targets. A Program can spawn/run a child with argv, env subset, and cwd and wait for an exit code; capture stdout/stderr, write stdin, and kill the child; and on native await child exit through the job queue / Promise. Tests under `tests/conformance/host/process` (subprocess fixtures) lock that combined surface. Mark H15 `done` only when those tests are green.
