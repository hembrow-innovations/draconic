# H00 Host I/O surface policy: module/global shape, error model, js hard-error vs polyfill matrix

## Why

ROADMAP H00 locks the Host I/O surface policy on both targets: module/global shape, the host error model, and the js hard-error vs polyfill matrix (ADR-0008). H00.01–H00.03 already land the registry, Runtime ABI scaffold, and bytes boundary; this cut is the parent row that those pieces form one honest policy.

## Done

ROADMAP H00 is implemented test-first on both targets. Host APIs have a locked module/global shape. Native host failures use the designed error model. JS-unavailable host APIs hard-error (no silent polyfill) until an explicit bridge row. Tests under `tests/conformance/host/policy` and `crates/draconic-runtime` lock that combined surface. Mark H00 `done` only when those tests are green.
