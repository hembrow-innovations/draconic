# Split mega-files along real internal seams

Parent: [[issues-6-architecture-cleanup]]

## Description

Soft ~1k LOC limit; multiple files 2–6× over. Split only on real conceptual seams; keep crate public interfaces stable.

## Affected

Oversize Rust sources under the toolchain crates (check, parser, ir, backends, runtime, etc.).

## Observed

Single-file = navigation boundary for agents. Seams already visible (bind vs check; lower vs class lower; promise classify vs async CPS; etc.).

## Impact

Review and Loop cost; AGENTS convention ignored.

## Proposed Fix

Incremental splits; one meaningful seam per work session unless trivially small.

## Agent Brief

### Goal

Reduce oversize Rust sources by splitting along **existing** conceptual seams without changing crate-level public behavior.

### Contract

- Soft target: files near or under ~1_000 lines where practical; do not invent shallow pass-through modules just to cut LOC.
- **One primary split per claim** of this issue (re-open or re-claim for the next file). Prefer highest recent churn among remaining offenders not actively owned by another in-flight architecture issue.
- Crate public interfaces stay stable unless a paired issue already authorizes a deepening.
- No behavior change: same diagnostics, emit, conformance.
- Good seam examples: Checker types vs bind vs check walks; IR types vs lower vs class desugar vs dump; Promise classify vs emit vs async CPS vs reactions; parser expr vs stmt vs class (link belongs to [[issues-11-linker-own-module]]).

### Acceptance criteria

1. At least one previously oversize file is split into modules along a named conceptual seam.
2. No new public API surface required for the split (or only `pub(crate)` internals).
3. `cargo test --workspace` green.
4. Comment on this issue listing what was split and the next recommended oversize target.

### Out of scope

- Deepening Frontend / Runtime ABI / LLVM façade (other issues).
- Blind alphabetical file chops without seam names.
- Hard CI fail on line count.
- Rewriting algorithms while splitting.
