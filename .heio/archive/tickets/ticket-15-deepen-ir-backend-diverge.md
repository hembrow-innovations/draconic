# Deepen IR where backends diverge

Parent: [[issues-6-architecture-cleanup]]

## Description

Shared IR (ADR-0002) has uneven depth: classes desugar in lower; async is flags; private-field state uses thread-locals. This issue’s **executable unit** is explicit lower context; async IR shape is deferred.

## Affected

IR lower (class/private); any tests that depend on lower isolation.

## Observed

Thread-local private-field maps in lower. Async still flag pass-through to JS vs special LLVM path.

## Impact

Hard-to-test lower; potential cross-test contamination; backend drift on async.

## Proposed Fix

Phase A (this brief): explicit lower context, no TLS. Phase B (human/later): async IR depth decision.

## Agent Brief

### Goal

Make IR **lower** testable and free of process-global mutable state by using an explicit lower context for private-field (and any similar) bookkeeping.

### Contract

- Lower no longer relies on thread-local or process-global mutable maps for private fields / brands / related class lowering state.
- An explicit context (parameter or struct owned by `lower`) carries that state for the duration of one lower.
- Observable JS and native behavior for private fields, classes, and existing fixtures unchanged.
- ADR-0002 unchanged (still one IR, two backends).
- **Do not** change async IR representation in this unit of work.

### Acceptance criteria

1. No thread-local (or equivalent global) mutable state required for correct class/private lowering.
2. Class / private-field conformance and unit tests green.
3. Parallel or repeated `lower` in one process cannot clobber each other’s private-field state (add a regression test if none exists).
4. `cargo test --workspace` green.
5. Comment noting async IR deepening remains open for a future issue/grill if dual-backend drift hurts.

### Out of scope

- Redesigning async as Promise/state-machine IR nodes (needs human grill; separate issue later).
- SSA/CFG IR rewrite.
- LLVM multi-path collapse ([[issues-10-collapse-llvm-multipath]]).
- Mega-file split of IR dump vs lower beyond what’s required for the context extraction ([[issues-12-split-mega-files-seams]]).
