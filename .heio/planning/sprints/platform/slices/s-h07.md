# H07 Async socket I/O + job queue

## Why

ROADMAP H07 locks the Host async socket surface on native: non-blocking readiness completed via the job queue, and Promise-shaped accept/connect/read/write that cancel/close cleanly. H07.01–H07.03 already land those pieces; this cut is the parent row that those ops form one honest async TCP surface on top of H06 sockets.

## Done

ROADMAP H07 is implemented test-first on native. A Program can set sockets non-blocking and complete readiness via the job queue, use async accept/connect/read/write that settle as Promises (cancel/close settles cleanly), and run concurrent connections without starving the job queue. Tests under `tests/conformance/host/net/async` and `crates/draconic-runtime` lock that combined surface. Mark H07 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **H07.01**: Non-blocking readiness; complete via job queue (already `done`)
- **H07.02**: Async accept/connect/read/write → Promises; cancel/close settles cleanly (already `done`)
- **H07.03**: Concurrent connections without starving job queue (already `done`)
- **H06**: TCP listen/accept/connect/read/write (sync sockets-first)
- **H08**: UDP
- **H05**: timers / run-loop wait
- **H10**: HTTP/1.1 helpers on sockets
