# D01 Release binaries + install script; one-line install to PATH

## Why

ROADMAP D01 locks the installable toolchain on the distribution location: a stranger can one-line install `draconic` onto PATH. D01.01–D01.03 already land host-triple release artifacts, the install script, and fresh-PATH smoke (`draconic -V` / parse hello); this cut is the parent row that those ops form one honest release-binaries + install-to-PATH surface.

## Done

ROADMAP D01 is implemented test-first on the compiler target. CI/release produces a host-triple platform binary. The install script downloads that artifact and places `draconic` on PATH in one line. After install, a fresh PATH can run `draconic -V` and parse a hello Program. Tests under `tests/integration` (`release_artifact`, `install_script`, `install_smoke`) lock that combined surface. Mark D01 `done` only when those tests are green.
