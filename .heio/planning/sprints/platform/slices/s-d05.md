# D05 Binary size opts: strip / LTO flags documented and testable

## Why

ROADMAP D05 makes native binary size opts honest: strip and LTO (or designed) flags are documented and testable from the CLI. Distribution already ships host artifacts; this cut stops leaving size knobs as undocumented cargo folklore.

## Done

ROADMAP D05 is implemented test-first on the native target. Docs name the strip and LTO (or designed) flags. Integration tests under `tests/integration` and CLI tests under `crates/draconic-cli` lock that those flags are documented and invokable. Mark D05 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **D05.01**: CLI/build flags that actually strip symbols
- **D05.02**: LTO (or designed) size-delta smoke
- **D04**: cross-compile matrix and CI jobs
- **D03**: reproducible-build byte identity
