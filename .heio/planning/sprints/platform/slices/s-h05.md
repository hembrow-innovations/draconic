# H05 Time, clock, timers (job-queue integrated)

## Why

ROADMAP H05 locks the Host time surface on both targets: wall clock, monotonic clock, and job-queue integrated timers. H05.01–H05.05 already land `Date.now` / `now_ms`, monotonic durations, `setTimeout` / `clearTimeout`, `setInterval` / `clearInterval`, and a run loop that waits for due timers; this cut is the parent row that those ops form one honest time surface.

## Done

ROADMAP H05 is implemented test-first on both targets. A Program can read wall-clock time (real OS time on native via `Date.now` / host `now_ms`), measure durations with a monotonic clock, schedule and cancel `setTimeout` / `clearTimeout` through the job queue, and schedule and cancel `setInterval` / `clearInterval`. Native run loop waits for due timers instead of busy-spinning forever. Tests under `tests/conformance/host/time` lock that combined surface. Mark H05 `done` only when those tests are green.

None.
