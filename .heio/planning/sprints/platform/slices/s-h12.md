# H12 WebSocket

## Why

ROADMAP H12 locks the Host WebSocket surface on native (ADR-0008 sockets-first; WebSocket later than plaintext HTTP/1.1). H12.01–H12.03 already land server-side HTTP/1.1 upgrade handshake, text/binary/close/ping/pong frames, and client dial + loopback text echo; this cut is the parent row that those ops form one honest WebSocket surface.

## Done

ROADMAP H12 is implemented test-first on native. A Program can complete a WebSocket handshake (HTTP/1.1 upgrade) server-side (`wsHandshakeResponse`), encode and decode RFC 6455 frames (text, binary, close, ping, pong), and dial as a client (`wsClientHandshakeRequest` / `wsClientCheckAccept` / `wsEncodeTextClient`) with loopback text echo. Tests under `tests/conformance/host/net/ws` lock that combined surface. Mark H12 `done` only when those tests are green.
