# K08 Integrity: verify lock hashes; refuse tampered cache

## Why

ROADMAP K08 locks package integrity on the compiler target (ADR-0009 git-backed packages). A locked checkout must recompute tree SHA-256 and match the lock pin, and a mismatched OID or hash must refuse the tree with no silent wrong content. K08.01–K08.02 already land recompute-and-hard-fail and refuse-mismatched-OID/hash; this cut is the parent row that those ops form one honest verify-lock-hashes / refuse-tampered-cache surface.

## Done

ROADMAP K08 is implemented test-first on the compiler target. Verifying a locked package recomputes the canonical tree SHA-256 and hard-fails on mismatch; mismatched checkout OID or content hash refuses the tree (no silent wrong tree). Tests in `crates/draconic-pkg` lock that combined surface. Mark K08 `done` only when those tests are green.
