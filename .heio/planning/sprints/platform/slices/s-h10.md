# H10 HTTP/1.1 thin helpers (plaintext) on sockets

## Why

ROADMAP H10 locks the Host HTTP/1.1 thin-helper surface on native (ADR-0008 sockets-first, then plaintext HTTP/1.1 on those sockets). H10.01–H10.07 already land request parse (line + headers + bounded body), response write, one-shot server, optional keep-alive, client request/response on connected TCP, chunked transfer encoding, and js listen-helper hard-error; this cut is the parent row that those ops form one honest HTTP/1.1 helper surface.

## Done

ROADMAP H10 is implemented test-first on native. A Program can parse an HTTP/1.1 request (request line, headers, Content-Length body), write a status + headers + body response, run a one-shot server (accept → parse → handler → write → close), optionally keep-alive two requests on one connection, issue a client request and read the response on connected TCP, and encode/decode Transfer-Encoding: chunked. JS HTTP listen helpers hard-error until an optional Node bridge. Tests under `tests/conformance/host/http` lock that combined surface. Mark H10 `done` only when those tests are green.
