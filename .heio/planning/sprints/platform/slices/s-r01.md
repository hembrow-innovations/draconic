# R01 Embed/eval resource limits: max source size, alloc/time budget

## Why

ROADMAP R01 makes embed/eval fail closed on native: max source size, alloc budget, and time budget are enforced together so a host cannot unbounded-eval. R01.01–R01.03 already land the three knobs; this cut is the parent row that the combined Embed + Runtime limits surface is honest.

## Done

ROADMAP R01 is implemented test-first on the native target. Embed `eval` / `Function` reject oversize source, fail closed when the alloc budget is exceeded, and interrupt/fail when the time budget is exceeded. Tests under `crates/draconic-embed` and `crates/draconic-runtime` lock that combined surface. Mark R01 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **R01.01**: max source size for embed/eval (already `done`)
- **R01.02**: alloc budget fail-closed (already `done`)
- **R01.03**: time budget interrupt (already `done`)
- **R02**: permission model (fs/net grants)
- **R04**: panic/abort vs catchable exception policy (ADR-0011 already classifies R01 exhaustion as fail-closed, not a JS exception)
- **N07**: embed `eval` / `Function` surface itself
