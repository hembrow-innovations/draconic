# R02.03 CLI/runtime flags to grant subset (opt-in permissions)

## Why

ROADMAP R02.03 makes opt-in permission grants invokable from the CLI and runtime: flags grant a subset of fs/net capabilities instead of leaving policy as an embed-only knob. H04/H06 already land the host surfaces; this cut is the flag surface of the optional Deno-like model (parent R02).

## Done

ROADMAP R02.03 is implemented test-first on both targets. CLI/runtime flags grant a subset of permissions. Tests under `crates/draconic-cli` and fixtures under `tests/conformance/fixtures/security/permissions` lock that a granted subset is honoured and an ungranted host op still fails closed. Mark R02.03 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **R02 parent remainder**: the umbrella grant/deny model row
- **R02.01**: permission grants: fs read/write, net listen/connect (as designed)
- **R02.02**: deny path: clear diagnostic when host op lacks grant
- **R02.04**: default policy documented (permissive vs locked-down as designed)
- **H04 / H06**: filesystem and TCP surfaces themselves
- **R01**: embed/eval resource limits
- **R04**: panic/abort vs catchable exception policy
