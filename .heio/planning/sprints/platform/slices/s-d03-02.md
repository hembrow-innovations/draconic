# D03.02 Same source + pin → byte-identical or documented-equivalent emit

## Why

ROADMAP D03.02 locks distribution emit identity: the same Program source plus the same toolchain pin yields byte-identical artifacts, or artifacts that match the documented-equivalent contract. D03.01 names timestamp and path expectations; this cut is the compiler emit so two builds can be compared, not only described.

## Done

ROADMAP D03.02 is implemented test-first on the compiler target. Building the same source twice with the same toolchain pin produces emit that is byte-identical, or matches the documented equivalent where byte identity is not promised. Integration tests under `tests/integration` lock that two-build comparison. Mark D03.02 `done` only when those tests are green.
