# H16 OS misc

## Why

ROADMAP H16 locks the Host OS-misc surface on both targets (ADR-0008 host I/O). H16.01–H16.04 already land cwd get + chdir, hostname / OS type / arch strings, temp dir + home dir paths, and native OS sleep / yield for timer tests; this cut is the parent row that those ops form one honest OS-misc surface.

## Done

ROADMAP H16 is implemented test-first on both targets. A Program can get and change cwd, read `hostname()` / `osType()` / `osArch()`, read `tempDir()` / `homeDir()`, and on native sleep / yield for timer tests. Tests under `tests/conformance/host/os` lock that combined surface. Mark H16 `done` only when those tests are green.
