# D04 Cross-compile matrix: linux/darwin/windows × amd64/arm64 (as available)

## Why

ROADMAP D04 locks the cross-compile matrix on the distribution location: linux/darwin/windows × amd64/arm64 as available. D04.01 is the non-host triple LLVM smoke; D04.02 is matrix docs and CI jobs. This cut is the parent row that those ops form one honest available-OS/arch compile surface.

## Done

ROADMAP D04 is implemented test-first on the native target. The toolchain can emit for the available linux/darwin/windows × amd64/arm64 pairs (pairs that are not available stay out of the sitting). Tests under `tests/integration` (`cross_compile`) lock that combined matrix, including LLVM backend emit. Mark D04 `done` only when those tests are green.
