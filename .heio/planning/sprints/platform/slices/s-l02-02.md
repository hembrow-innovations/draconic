# L02.02 Deque (or designed): push/pop both ends

## Why

ROADMAP L02.02 locks the stdlib Deque surface on both targets (stdlib location: honest portable libs a simple service needs; not a second Array/Map/Set). L02.01 covers array groupBy/chunk; this cut is the double-ended queue a Program can push and pop from both ends.

## Done

ROADMAP L02.02 is implemented test-first on both targets. A Program can construct a Deque (or designed name) and push/pop at both ends without treating Array as that type. Tests under `tests/conformance` fixtures `stdlib/collections` lock that surface. Mark L02.02 `done` only when those tests are green.
