# P04 Flagship service example: typed HTTP + fs/config + git dep (after H17 + K09)

## Why

ROADMAP P04 makes a flagship service example honest: one in-repo Program under `examples/` that combines typed HTTP, filesystem config, and a git module dependency after H17 success programs and K09 package e2e. P01 is fizzbuzz; H17 is http-echo/todo; K10 is pkg-lib/pkg-consumer. This cut is the service that uses all three together on both targets.

## Done

ROADMAP P04 is implemented test-first on both targets. An example under `examples/` uses typed HTTP, reads config via host fs, and depends on a git module path. Integration tests lock native HTTP + fs/config + git-dep behavior. The js target builds and runs the portable config/git-dep path (HTTP listen stays native-first per ADR-0008 / H10.07). Mark P04 `done` only when those tests are green.

## Blocked by

None. H17.01–H17.03 already land http-echo and todo native serve; K09.01–K09.02 already land temp git dep + consumer e2e. H17.04 optional JS/Node bridge is not this cut.
