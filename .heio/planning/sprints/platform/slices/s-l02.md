# L02 Collections helpers (groupBy/chunk/Deque as designed; not redundant with Array/Map/Set)

## Why

ROADMAP L02 locks the stdlib collections helper surface on both targets (stdlib location: honest portable libs a simple service needs). groupBy/chunk and Deque (or designed names) are the designed ops; this cut is the parent row that those ops form one collections helper library that is not a redundant Array/Map/Set clone.

## Done

ROADMAP L02 is implemented test-first on both targets. A Program can use designed collections helpers — groupBy/chunk on arrays and a Deque with push/pop at both ends (or designed names) — without those ops duplicating Array, Map, or Set. Tests under `tests/conformance` fixtures `stdlib/collections` lock that combined surface. Mark L02 `done` only when those tests are green.

## Blocked by

None. The ticket names no dependency. L02.01 and L02.02 land the per-class groupBy/chunk and Deque fixtures this parent row unifies.

## Non-goals

- **L02.01**: `groupBy` / `chunk` (or designed names) on arrays
- **L02.02**: Deque (or designed): push/pop both ends
- **L01**: Encoding UTF-8 / Base64 / hex
- **L03**: Crypto SHA-256 / CSPRNG
- **L07**: Flags/CLI parse

- Re-filing Array, Map, or Set ECMA-262 builtins as collections helpers
