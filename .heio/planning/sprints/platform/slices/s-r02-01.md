# R02.01 Permission grants: fs read/write, net listen/connect (as designed)

## Why

ROADMAP R02.01 makes permission grants honest: when the designed policy grants fs read/write or net listen/connect, those host ops succeed. H04/H06 already land the host surfaces; this cut is the grant path of the optional Deno-like model (parent R02).

## Done

ROADMAP R02.01 is implemented test-first on both targets. Fixtures under `tests/conformance/fixtures/security/permissions` lock that granted fs read/write and net listen/connect host ops succeed as designed. Mark R02.01 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **R02 parent remainder**: the umbrella grant/deny model row
- **R02.02**: deny path: clear diagnostic when host op lacks grant
- **R02.03**: CLI/runtime flags to grant subset (opt-in permissions)
- **R02.04**: default policy documented (permissive vs locked-down as designed)
- **H04 / H06**: filesystem and TCP surfaces themselves
- **R01**: embed/eval resource limits
- **R04**: panic/abort vs catchable exception policy
