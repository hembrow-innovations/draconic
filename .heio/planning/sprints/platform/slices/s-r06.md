# R06 Panic backtraces with source locations (ties U07 DWARF)

## Why

ROADMAP R06 makes panic backtraces with Draconic source locations honest on native. U07 already lands DWARF mapping Draconic source lines; this cut is the Runtime abort/panic path using that mapping so a process abort names user source, not only libc frames.

## Done

ROADMAP R06 is implemented test-first on the native target. Runtime tests under `crates/draconic-runtime` lock that abort-class faults emit a backtrace. Integration tests under `tests/integration` lock that a native panic/abort of a Draconic program reports Draconic source locations via U07 DWARF. Mark R06 `done` only when those tests are green.

## Blocked by

None. U07 already lands DWARF source-line mapping this row consumes.

## Non-goals

- **U07**: native DWARF debug info mapping Draconic source lines (already `done`)
- **U03**: JS source maps
- **R04**: panic/abort vs catchable exception policy
- **R04.01 / R04.02**: catchable vs abort class fixtures (already `done`)
- **R05**: fuzz/stress hooks
- **N09**: GC stress
