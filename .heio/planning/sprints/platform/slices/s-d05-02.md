# D05.02 LTO (or designed) flag documented; size delta smoke

## Why

ROADMAP D05.02 makes native binary size honest at the LTO seam: `draconic build` exposes an LTO (or designed) flag, docs name it, and a size-delta smoke shows the LTO artifact versus the default native build. Distribution already produces host binaries; this cut stops leaving LTO as cargo folklore.

## Done

ROADMAP D05.02 is implemented test-first on the native target. The LTO (or designed) flag is documented and invokable from the CLI. Tests under `crates/draconic-cli` and `tests/integration` lock that the flag is documented and that a size-delta smoke compares LTO versus default native artifacts. Mark D05.02 `done` only when those tests are green.

## Blocked by

None.

## Non-goals

- **D05.01**: CLI/build flags that strip symbols
- **D05 parent remainder**: documenting strip and LTO together as one umbrella row
- **D03**: reproducible-build byte identity
- **U07**: native DWARF debug-info emit; LTO does not re-litigate debug mapping
