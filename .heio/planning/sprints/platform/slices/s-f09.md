# F09 Optional later: wasm32/wasi emit + link smoke

## Why

ROADMAP F09 locks optional later wasm32/wasi emit plus a link smoke on the LLVM backend (ADR-0002: one shared IR, no WASM-only fork). F09 is later than the F v1 bar (F06 + F01 + F08 + F04). The cut is still one atomic Loop so a Program can emit for wasm32/wasi and link that artifact without leaving Draconic.

## Done

ROADMAP F09 is implemented test-first on native. The LLVM backend emits for wasm32/wasi from the shared IR, and a link smoke produces a linked wasm artifact (not a full WASI runtime). Tests under `tests/integration` and `crates/draconic-backend-llvm` lock that emit+link surface. Mark F09 `done` only when those tests are green.

## Blocked by

None. The ticket names no dependency.

## Non-goals

- **F01**: `extern "C"` call out (scalar args/returns)
- **F04**: Link external static lib (`.a`)
- **F05**: Load dynamic lib
- **F06**: Manual `extern` decls
- **F08**: Unsafe/native-only FFI diagnostics
- **D04**: linux/darwin/windows × amd64/arm64 cross-compile matrix
- a third WASM-only IR (ADR-0002 rejected that)
- full WASI libc / preview2 host, browser wasm, or wasmtime identity
- changing the F v1 done bar to require F09
