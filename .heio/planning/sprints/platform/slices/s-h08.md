# H08 UDP

## Why

ROADMAP H08 locks the Host UDP surface on native (ADR-0008 sockets-first). H08.01–H08.02 already land bind/sendto/recvfrom/close and loopback e2e; this cut is the parent row that those ops form one honest UDP surface.

## Done

ROADMAP H08 is implemented test-first on native. A Program can bind a UDP socket (port 0 → ephemeral + query local port), sendto/recvfrom bytes, close the handle, and complete a loopback send + echo. Tests under `tests/conformance/host/net/udp` lock that combined surface. Mark H08 `done` only when those tests are green.
