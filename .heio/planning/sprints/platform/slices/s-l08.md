# L08 URL / query parse + serialize

## Why

ROADMAP L08 locks the stdlib URL and query parse/serialize surface on both targets (stdlib location: honest portable libs a simple service needs). L08.01–L08.02 already land `parseUrl` (scheme/host/path/query/hash) and `parseQuery` / `serializeQuery` with common-case round-trips; this cut is the parent row that those ops form one URL library. L08 is on the L v1 done bar.

## Done

ROADMAP L08 is implemented test-first on both targets. Tests under `tests/conformance` fixtures `stdlib/url` lock that combined surface. Mark L08 `done` only when those tests are green.
