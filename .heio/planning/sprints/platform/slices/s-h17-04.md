# H17.04 Optional JS/Node bridge for subset host APIs (after native green)

## Why

ROADMAP H17.04 locks the optional JS/Node bridge for a designed subset of host APIs on the js target after native success programs are green (ADR-0008: JS hard-error or host polyfill per row, no silent polyfill). H17.01–H17.03 already land `examples/http-echo`, the echo integration, and `examples/todo` native serve. H06.06 / H09.03 / H10.07 currently hard-error TCP listen/accept, `dnsLookup`, and HTTP listen helpers on js until this explicit bridge row.

## Done

ROADMAP H17.04 is implemented test-first on js. A designed subset of host APIs that previously hard-errored on js now run via an explicit Node bridge. Host APIs outside that subset still hard-error (no silent polyfill). Tests under `tests/conformance` fixtures `host/policy` lock that matrix. Mark H17.04 `done` only when those tests are green.

## Blocked by

None. H17.01–H17.03 already land native http-echo and todo serve.
