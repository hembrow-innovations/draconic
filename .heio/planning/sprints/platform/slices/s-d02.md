# D02 Toolchain version pin in `draconic.toml`; CLI enforces or warns

## Why

ROADMAP D02 locks the installable toolchain pin on the distribution location: a Program names a toolchain version in `draconic.toml` and the CLI enforces or warns when the running toolchain does not match. D02.01–D02.02 already land the manifest field and the mismatch path; this cut is the parent row that those ops form one honest pin + enforce/warn surface.

## Done

ROADMAP D02 is implemented test-first on the compiler target. `draconic.toml` can carry a required or optional toolchain version pin. The CLI warns or hard-fails when the running toolchain ≠ that pin. Tests under `crates/draconic-cli` and `tests/integration` (`toolchain_pin`) lock that combined surface. Mark D02 `done` only when those tests are green.
