# H06 TCP sockets (sockets-first)

## Why

ROADMAP H06 locks the Host TCP socket surface on native (ADR-0008 sockets-first). H06.01–H06.06 already land listen/bind/backlog/ephemeral port, accept + peer address, connect with refused/timeout errors, read/write/partial/close/shutdown, loopback echo, and js listen/accept hard-error; this cut is the parent row that those ops form one honest TCP surface.

## Done

ROADMAP H06 is implemented test-first on native. A Program can listen (bind, backlog, close; port 0 → ephemeral + query local port), accept a connection handle with peer address, connect to host:port (refused/timeout are typed errors), read/write bytes with partial read and close/shutdown, and complete a loopback listen + connect + echo + close. JS TCP listen/accept hard-errors until an optional Node bridge. Tests under `tests/conformance/host/net/tcp` lock that combined surface. Mark H06 `done` only when those tests are green.
