# H03 Path helpers (string ops; no I/O)

## Why

ROADMAP H03 locks the Host path-helper surface on both targets: string path ops with no I/O. H03.01–H03.03 already land join/normalize, dirname/basename/extname/isAbsolute, and resolve-relative-to-cwd; this cut is the parent row that those ops form one honest path surface.

## Done

ROADMAP H03 is implemented test-first on both targets. A Program can `path.join` / `path.normalize` (POSIX + Windows-aware as designed), `dirname` / `basename` / `extname` / `isAbsolute`, and `path.resolve` relative to cwd. Path helpers stay string ops with no filesystem I/O. Tests under `tests/conformance/host/path` lock that combined surface. Mark H03 `done` only when those tests are green.
