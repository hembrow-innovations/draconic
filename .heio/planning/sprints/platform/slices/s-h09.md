# H09 DNS

## Why

ROADMAP H09 locks the Host DNS surface on native (ADR-0008 sockets-first). H09.01–H09.03 already land hostname lookup with failure errors, connect-by-name on top of H06.03, and js `dnsLookup` hard-error; this cut is the parent row that those ops form one honest DNS surface.
