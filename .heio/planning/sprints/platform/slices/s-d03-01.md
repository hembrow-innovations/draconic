# D03.01 Document reproducibility expectations (timestamps, paths)

## Why

ROADMAP D03.01 makes distribution honesty start with words: docs name what same source plus pin promises for timestamps and embedded paths, so operators can tell whether two artifacts should match before D03.02 locks emit identity.

## Done

ROADMAP D03.01 is implemented test-first on the compiler target. Docs name reproducibility expectations for timestamps and paths. Integration tests under `tests/integration` lock that those docs exist and cover timestamps and paths. Mark D03.01 `done` only when those tests are green.

## Blocked by

None.

- **D03 parent remainder**: combining docs + emit identity as one umbrella row
- **D02**: Toolchain version pin in `draconic.toml`
- **D01**: Release binaries + install script
