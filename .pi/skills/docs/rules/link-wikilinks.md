# Wikilinks only

Link note to note with `[[note-name]]` or `[[note-name|alias]]`. Relative `.md` paths break on moves.

After any rename, search `docs/` for the old path and fix leftovers before you commit.

A docs note may wikilink a working file by `id` (`[[plan-2-auth]]`). The working file itself lives under `.heio/`. Load the **management** skill to create or close it.
