# Before writing

Search `.heio/` first. Update in place over near-dupes. A second intent, a second roadmap, or a second `tasks.md` on an inactive slice is a miss.

1. Pick the kind. Copy the matching file from `templates/`.
2. Place and name per `layout.md`.
3. Leave reserved root files alone (`TODO.md`, `decisions.tsv`, `oracles.md`, `worktrees/`, `sessions/`, `teams/`).
4. Touch `updated_at` on every edit. The h1 string matches `title`.

Done when the path, filename, and template kind all match `layout.md` and `template-kinds.md`.
