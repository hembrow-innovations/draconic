# Before writing

Search `.heio/` first, including `archive/`. Update in place over near-dupes. Do not recreate archived work as live without saying so.

1. Pick the kind. Copy the matching file from `templates/`.
2. Place and name per `layout.md`.
3. Leave reserved root files alone (`TODO.md`, `decisions.tsv`, `worktrees/`, `sessions/`, `teams/`).
4. Touch `updated_at` on every edit. The h1 string matches `title`.

Done when the path, filename, and template kind all match `layout.md` and `template-kinds.md`.
