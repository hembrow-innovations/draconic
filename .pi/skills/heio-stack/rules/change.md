# How change enters

Inbound **product** work is a **ticket** first. Never a task. Map hygiene is a map edit, not a ticket: adding a location, a truth link, a sub-map, or an archive line is editing the map.

Same triage every time (`rules/tickets.md` and `rules/loop.md`):

- Fits an unblocked active slice → **TASK**
- Fits the project, not this slice → **TICKET**
- Would rewrite a location destination → **ESCALATE**
