# Make Runtime ABI a real seam

Parent: [[issues-6-architecture-cleanup]]

## Description

Runtime publishes symbol-name constants the LLVM backend largely ignores; emitters hardcode `@draconic_rt_*` declares and calls as strings. ABI knowledge leaks; signature drift is multi-file.

## Affected

Runtime public surface and LLVM backend native / Promise / eval emit paths.

## Observed

Backend link step uses Runtime’s static-lib builder; semantic ABI is stringly typed in emit. Duplicate clang-discovery style glue may exist across crates.

## Impact

Promise/async/eval work re-touches string soup; C header and emit can diverge.

## Proposed Fix

One ABI-owned interface for names + LLVM declare/call helpers; emitters consume it.

## Agent Brief

### Goal

Make the **Runtime** ABI a real seam: one place owns C ABI symbol names and the LLVM-text declare/call shapes the backend needs.

### Contract

- Symbol names used in linked native binaries remain the Runtime C ABI (no silent rename of exported C functions without updating both sides together).
- LLVM backend emit paths (native ints/layouts, Promise/async, eval observations) obtain symbol names and/or declare snippets from the Runtime ABI surface — not from ad-hoc string literals duplicated per emitter.
- Existing Runtime `*_SYMBOL` constants become the single source (or are replaced by an equivalent structured ABI API); dead dual sources are not left behind.
- Observable native binary behavior and conformance native stdout unchanged.
- Domain terms: Runtime, LLVM backend, Embed (unchanged).

### Acceptance criteria

1. LLVM backend emit no longer hardcodes Runtime symbol names that already exist (or should exist) on the Runtime ABI surface — wired through that surface.
2. Adding or renaming an ABI symbol is a one-module change plus C implementation, not a hunt across three emitters.
3. Native Promise / native-int / eval-related tests and conformance fixtures that already pass still pass.
4. `cargo test --workspace` green.

### Out of scope

- Collapsing the three LLVM path modules into one lowerer ([[issues-10-collapse-llvm-multipath]]) — may share helpers afterward, not required here.
- Changing Promise/job-queue semantics in C.
- Full GC redesign.
- Frontend compile module ([[issues-8-deepen-frontend-compile-module]]).

### Suggested pickup order

Before or with [[issues-10-collapse-llvm-multipath]] (ABI seam unlocks shared declare sets).
