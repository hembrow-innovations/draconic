# Public docs: Draconic-generated Learn + Reference site

Public language docs are a static site generated by a Draconic Program, not mdBook, Starlight, or VitePress. Sources live in `website/` as a markdown subset (headings, paragraphs, lists, code fences, links, status frontmatter). The generator emits HTML with two sections, **Learn** and **Reference**. GitHub Pages publishes the output from CI.

The site describes the language as designed and tags each page shipped or not-yet. Copy-paste code exists only on shipped pages and must build; CI extracts those fences and compiles them. Playground and in-page runners are later. Agent/toolchain notes stay under `docs/`; they are not the public site.

Rejected: serving the vault as the site; a linear mdBook; a Node docs generator as the source of truth; documenting samples that do not compile.
