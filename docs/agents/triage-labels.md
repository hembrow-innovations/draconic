# Triage Labels

**Canonical guide:** [`docs/reference/guides/triage-labels.md`](../reference/guides/triage-labels.md)

Roles map to issue frontmatter (`status` + `tags`), not GitHub labels.

- Category tags: `bug` | `enhancement`
- State: `needs-triage` | `needs-info` | `ready-for-agent` | `ready-for-human` | `wontfix`
- Terminal: set `status: closed` or `wontfix` **and** move note to `docs/planning/issues/closed/`
