# Kernel travels, dialect does not

The **kernel** carries to any project unchanged:

- Spec is a folder of `purpose.md`, `contract.md`, `test.md`
- Purpose is job and fences
- Contract, promise, asserted vs locked, scope hierarchy
- Subtractive archetype inheritance, tree and backlink navigation
- Dumb checker, paved-path
- Stable filenames are the AI index; the path is the human taxonomy
- Read purpose first. Empty ladder means stop
- Changing behaviour is a visible promise edit

The **dialect** is per-project: domain and area names, tracker path, packer command, checker script, archetype library. Discover those. Do not copy another product's words.

This skill names no routes, tabs, tables, or apps. Example trees in other rules are examples.

If the repo already has a spec layout under a different path, use it. Port the grammar. Fill in the words.
