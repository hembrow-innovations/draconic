# docs is truth, .heio is day to day

`docs/` is committed. A clone sees it. Write here when the next person needs the note without this machine.

`.heio/` is local working memory. Git ignores it. Tickets, slices, tasks, rounds, and archive live there.

Do not keep two living copies. Promote a finished outcome by writing it as an ADR, spec, architecture note, or guide. Then close the working file with the **management** skill.

Do not copy a slice or task into `docs/` as a plan. The kind must change.

This skill stops at `docs/`.
