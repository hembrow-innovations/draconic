## Run the printed help follow-up

Every response ends with `help[]` next-step templates. AXI contextual disclosure. Those lines are the next call.

**Incorrect:** Ignoring `help[]` and inventing a different subcommand or path.

**Correct:** Run the suggested command through the binary from `disc-cli-binary`. Keep fixed flags. Fill `<id>` / path placeholders from the TOON above.

Notes: If the suggestion starts with `obsidian-axi`, prefix with `npx -y @andershoffmann/obsidian-axi` when that is the binary you resolved. `--help` is for when the hints are not enough.
